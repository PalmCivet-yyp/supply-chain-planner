# 1.0 基线计算规则

仅对应 `scripts/plan_inventory.py`；2.0 模块化入口见 [引擎说明](v2-engine.md)。

本版本实现单层、定期复核的库存位置补货基线，并独立检验到货时序。将所有规则视为可审查的分析约定，不将其称为企业标准或全局最优策略。

## 时间和净库存

以 `t0` 为快照日收盘。未来第 d 天先收到当日 confirmed 在途，再扣当天预测新增需求。普通新单在 `t0 + L` 当日早上到货。负预测净结余表示累计未交需求，后续到货先抵消欠单；本版本不模拟丢单。

`A0 = on_hand − reserved − backorders`。

`IP = A0 + 全部未来 confirmed 在途未交量`。区分全部库存位置、保护期内供应和实物库存，不把其互相替代。

## 预测和滚动评估

使用平均最近 28 天、平均最近 7 天、重复最近 7 天的逐日模式三个非负基线。固定每个 SKU 的预测评估跨度为 `H = L + R`。从至少 28 天训练数据开始，对最多最后 14 个可完整观察 H 天的历史起点进行滚动评估。每次只用起点之前的数据预测，允许评估窗重叠；报告其非独立性。

至少有 8 个可评估起点时，以所有 H 天预测的逐日 MAE 最小为主、H 天累计误差绝对值平均为次进行选择；完全相同时优先 28 天平均。报告 WAPE = Σ|实际−预测| / Σ实际，分母零时写 null；不将 WAPE 称为准确率，不用 1−WAPE 表示业务成效。

历史不足以提供 8 个起点时，使用 28 天平均作为条件情景，不声称完成模型验证。历史不足 28 天或存在未解释缺失日时，不输出可执行数量。

## 安全库存

数据可支持滚动评估时，取入选基线在每个起点的 H 天累计误差 `e = 实际 − 预测`，计算样本标准差 s_e 与均值 b。使用 `SS = max(0, b) + z × s_e`，其中 `z = NormalDist().inv_cdf(service_level)`。保留正偏差缓冲是本 Skill 的保守实现约定，必须披露；不要把它说成 MIT 或 ERP 的原公式。

可评估起点不足时，回退至 `SS = z × s_daily × sqrt(H)`，并将状态标为条件情景。这个回退要求近似独立、稳定的日需求；明显趋势、间歇需求、促销、长期相关或交期波动需要其他处理。累计误差方法也受样本短、重叠窗口、近似正态与需求变化影响；z 对应设计周期服务目标，不证明实际达标，也不是数量满足率。

需求倍率情景将预测与历史误差尺度同时乘以倍率，标为“条件情景”。增加交期重新计算 H 和历史评估，不修改原始在途 ETA。近 7 天均值相对此前 21 天大于 1.5 或小于 2/3 时标记变化，属于实现中的诊断阈值。

## 补货数量和到货时间

`S = Σ未来 H 天预测 + SS`。

`raw_gap = max(0, S − IP)`。

raw_gap 为 0 时，Q = 0；否则 `Q = pack_size × ceil(max(raw_gap, moq) / pack_size)`。

不以库存位置替代逐日模拟。分别模拟不新增订单和在 L 天后加入 Q 的净结余；报告首次短缺、普通到货之前的最大净缺口，以及保护期内最大净缺口。全部未来在途都会抵扣 IP；保护期之后的供应另报数量，不能用其保证今天不缺货。

若远期在途已覆盖 S 但近期仍缺货，常规 Q 可以为 0。优先检查催交或分批提前；若新增订单，必须同时评估取消/推迟原远期供应或容忍积压。禁止直接将短缺缺口再下成第二份订单。

## 状态与优先级

- `blocked`：历史不足/缺日、全零或零需求日不少于一半、sales 期间缺货或缺货状态未知、逾期 confirmed 在途。保留诊断，Q 为 null。
- `scenario_only`：未充分滚动评估、仅有无缺货标志的 sales、未确认在途、显著需求变化、显式填零、需求倍率或交期情景。数量只作为有条件估计。
- `ready_for_review`：未触发上述状态，仍需业务复核，不能自动下单。
- P0：数据或业务口径阻断。P1：当前或普通新单到达前预测出现欠单。P2：其他保护期内短缺或 Q 大于 0。P3：其他。

可售可用量除以正日均预测得到静态库存覆盖天数；日均预测为 0 时返回 null。覆盖超过 `--excess-cover-days` 默认 90 天时标为“超过情景阈值”，不是自动认定滞销或报废。阈值应结合品类、保质期和供应周期重设。

## 金额和未覆盖约束

估算采购货值 = Q × unit_cost，按行保留 currency；不混币种加总，不作为总持有成本、节省额或预算最优分配。未模拟预算、共享产能、保质期、生命周期、BOM、双供应商、多级网络、交期概率分布或跨仓运输时间。
